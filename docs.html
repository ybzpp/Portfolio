Telegram-уведомления

При отправке формы с сайта запрос уходит на POST /api/contact. API отправляет сообщение в Telegram. Без настроенного бота форма вернёт ошибку «Telegram not configured».

Шаг 1: Создать бота и получить токен

  1. Откройте в Telegram @BotFather.
  2. Отправьте /newbot, укажите имя и username бота.
  3. Скопируйте выданный токен (вид: 123456789:ABCdefGHI...). Это TELEGRAM_BOT_TOKEN.

Шаг 2: Узнать Chat ID

Личные сообщения вам:

  1. Напишите созданному боту любое сообщение (чтобы был диалог).
  2. Откройте @userinfobot, отправьте ему любое сообщение.
  3. Бот пришлёт ваш Id — это и есть TELEGRAM_CHAT_ID (число, например 123456789).

Группа: добавьте бота в группу, напишите в группе сообщение, затем откройте в браузере:

https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates

В ответе найдите "chat":{"id":-123456789} — этот id и есть chat_id для группы.

Шаг 3: Прописать в .env

Локально (для разработки) и на сервере создайте или отредактируйте файл .env в корне проекта:

# Копировать из .env.example
TELEGRAM_BOT_TOKEN=123456789:ABCdef...
TELEGRAM_CHAT_ID=123456789

На сервере после изменения .env перезапустите приложение: pm2 restart portfolio.

Важно: .env не коммитить в Git. В репозитории уже есть .env.example с подсказками — на сервере создайте свой .env по этому образцу.

Админка

В проекте нет встроенной веб-админки. Все заявки с формы обратной связи приходят в Telegram — это и есть канал уведомлений для вас.

Если позже понадобится админ-панель (например, просмотр заявок в браузере или редактирование проектов), её нужно будет добавить отдельно: страница /admin, авторизация (логин/пароль или OAuth) и при необходимости база данных.

Деплой на VPS (Ubuntu 24.04)

Краткий порядок действий. Подробные команды — в файле DEPLOY.md в корне проекта.

  1. Сервер: Ubuntu 24.04, SSH-доступ.
  2. Установить: Node.js 20, Nginx, PM2, Git.
  3. Проект: клонировать в /var/www/portfolio, создать .env с Telegram-переменными, выполнить npm install, npm run build, запуск через pm2 start npm --name "portfolio" -- start.
  4. Nginx: конфиг в /etc/nginx/sites-available/portfolio с server_name = ваш домен и proxy_pass http://127.0.0.1:3000.
  5. Домен: у регистратора домена создать A-записи для @ и www на IP VPS.
  6. SSL: sudo apt install certbot python3-certbot-nginx, затем sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com.

Обновление после изменений: git pull → npm install → npm run build → pm2 restart portfolio.

Выкачать с Git нужную ветку сразу в /var/www/portfolio

Чтобы клонировать не main, а нужную ветку (например new-site) сразу в целевую папку:

sudo mkdir -p /var/www && sudo chown $USER:$USER /var/www
git clone -b new-site https://github.com/ВАШ_ЮЗЕР/Portfolio.git /var/www/portfolio
cd /var/www/portfolio

Через SSH: git clone -b new-site git@github.com:ВАШ_ЮЗЕР/Portfolio.git /var/www/portfolio.

Если папка уже есть и нужно только подтянуть ветку:

cd /var/www/portfolio
git fetch origin
git checkout new-site
git pull origin new-site

Деплой одной командой (Docker)

Не хотите вручную ставить Node, Nginx как reverse proxy оставляете, приложение крутится в контейнере.

  1. На VPS один раз установите Docker и Docker Compose (команды — в DEPLOY.md, раздел 4a).
  2. Выкатите проект с нужной ветки и запустите одной командой:
REPO=https://github.com/ВАШ_ЮЗЕР/Portfolio.git BRANCH=new-site ./deploy.sh

Скрипт deploy.sh из репозитория клонирует ветку в /var/www/portfolio, при отсутствии создаёт .env из примера и запускает docker compose up -d --build. Первый раз после этого создайте/заполните .env (Telegram) и снова выполните docker compose up -d --build.

Дальше настраиваете Nginx (proxy_pass на http://127.0.0.1:3000) и SSL через Certbot — как в разделе Деплой на VPS.

Обновление: cd /var/www/portfolio && git pull origin new-site && docker compose up -d --build или снова BRANCH=new-site ./deploy.sh.

Переменные окружения на сервере

На VPS в корне проекта должен быть файл .env с переменными, которые использует приложение. Сейчас это только Telegram:

ПеременнаяОписание
TELEGRAM_BOT_TOKENТокен бота от @BotFather
TELEGRAM_CHAT_IDID чата (личный или группы), куда слать уведомления

Создание файла на сервере:

cd /var/www/portfolio
nano .env

Вставьте строки с подставленными значениями. После сохранения: pm2 restart portfolio.
